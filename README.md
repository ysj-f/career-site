## 1. ページ構成

`index.html` をダブルクリックすると、ブラウザでそのまま確認できます（ネット接続不要）。

| ファイル名 | ページ | 内容 |
|---|---|---|
| `index.html` | トップ | 入口。3つの魅力、仕事内容、募集概要の要約 |
| `about.html` | 事業について | 立ち上げの背景、学生の担当範囲、事業計画づくりの中身 |
| `program.html` | プログラム | 研修の流れ、1日の流れ、金曜ミーティング、成長ステップ |
| `recruit.html` | 募集要項 | 勤務条件の一覧、応募から参加までの流れ |
| `for-universities.html` | 大学の皆さまへ | 教育的位置づけ、労務・安全面、ご相談いただけること |
| `faq.html` | よくある質問 | 応募／働き方／仕事内容／条件 の4カテゴリ |

その他のファイル

- `assets/style.css` … デザイン（色・文字サイズ）
- `assets/config.js` … **応募フォームURL・電話・メールをまとめて設定する場所**
- `assets/main.js` … メニュー開閉などの動作（触らなくてOK）
- `assets/img/` … 写真

## 2. 無料で公開する（GitHub Pages）

ブラウザ上で修正できるようにするため、**GitHub** に置く方法をおすすめします。
無料で、独自のURLが持て、修正した瞬間に自動でサイトへ反映されます。

### 手順（初回だけ・15分ほど）

1. [https://github.com](https://github.com) を開き、無料アカウントを作成
   （メールアドレスとパスワードだけで作れます。クレジットカード不要）
2. 右上の **＋** → **New repository** を選ぶ
3. 設定
   - Repository name：`career-site` など（英数字）
   - **Public** を選択（Publicでないと無料公開できません）
   - 「Add a README file」は**チェックを入れない**
   - **Create repository** をクリック
4. 次の画面の **uploading an existing file** をクリック
5. `ysj-career-site` フォルダを開き、**中身をすべて選択**して枠にドラッグ＆ドロップ
   （※フォルダごとではなく、`index.html` などが直接並ぶようにします）
6. 下の **Commit changes** をクリック
7. 上部メニューの **Settings** → 左メニューの **Pages** を開く
8. Branch を `main`、フォルダを `/ (root)` にして **Save**
9. 1〜3分待つと、上部に公開URLが表示されます
   `https://（ユーザー名）.github.io/career-site/`

このURLを、大学や学生に共有できます。

> **補足**：Googleサイト（Google Sites）は、この形式のHTMLをそのまま載せることができません。
> Googleアカウントは**応募フォーム（Googleフォーム）**の方で活用し、
> サイトの公開はGitHub Pagesで行うのがおすすめです。どちらも無料です。

## 3. 公開後、ブラウザ上で直接修正する

GitHubに置くと、**パソコンにファイルを持っていなくても、ブラウザだけで修正できます。**

### かんたんな直し方（1か所だけ直すとき）

1. GitHubの自分のリポジトリを開く
2. 直したいファイル（例：`recruit.html`）をクリック
3. 右上の **鉛筆マーク（✏️ Edit this file）** をクリック
4. 文章を書き換える
5. 右上の **Commit changes...** → もう一度 **Commit changes** をクリック
6. **1〜2分でサイトに反映されます**（更新後、ブラウザで再読み込み）

### まとめて直したいとき（おすすめ）

リポジトリの画面でキーボードの **`.`（ピリオド）** を押すと、
ブラウザ上に本格的な編集画面（VS Code）が開きます。
複数ファイルを見ながら編集でき、左下の枝マーク → **Commit & Push** で反映されます。

### 迷子にならないための目印

各HTMLファイルの中には、次のような目印を入れています。

```html
<!-- ▼▼▼ ここから：募集概要 ▼▼▼ -->
```

ブラウザの検索（Ctrl+F / Command+F）で「募集概要」と打てば、直したい場所にすぐ飛べます。

### 編集するときの注意

- `<` と `>` で囲まれた部分（タグ）は**触らない**
- タグとタグの**あいだの日本語だけ**を書き換える

```html
<h3>事業計画を、自分たちの手で</h3>
     ↑ ここだけ変える
```

- 万が一おかしくなっても、GitHubは変更履歴が全部残るので**いつでも元に戻せます**
  （ファイルの **History** → 戻したい時点を選択）

## 4. 応募データはどこに集まるか

### 大前提：このサイト自体はデータを保存しません

このサイトは文章と画像だけの静的なページで、データベースやサーバー機能を持っていません。
**応募ボタンは、Googleフォームへリンクしているだけ**です。
したがって、応募者の個人情報がこのサイトやGitHubに残ることは一切ありません。

### データの流れ

```
学生がサイトの「応募する」ボタンを押す
        ↓
Googleフォームが開く（別画面）
        ↓
学生が入力して送信
        ↓
┌─────────────────────────────────┐
│ ① Googleフォームの「回答」タブ            │  ← 一覧で見られる
│ ② 連携したGoogleスプレッドシート          │  ← 表で管理・並べ替え・書き出しができる
│ ③ 指定したメールアドレスへ通知             │  ← 応募が来たらすぐ気づける
└─────────────────────────────────┘
```

### ① 回答の確認場所

作成したGoogleフォームを開き、上部の **「回答」** タブ。
何件届いているか、個別の内容がここで確認できます。

### ② スプレッドシートに集約する（推奨）

「回答」タブ → 右上の **スプレッドシートのアイコン（緑）** → **新しいスプレッドシートを作成**。
以降、応募が入るたびに自動で1行ずつ追加されていきます。
選考状況の列を自分で追加して、進捗管理表としても使えます。

### ③ 応募が来たらメールで知らせる

「回答」タブ → 右上の **⋮（縦三点）** → **新しい回答についてメール通知を受け取る** をON。
フォームを作成したGoogleアカウントのアドレスに通知が届きます。

### 誰が見られるか

- 初期状態では、**フォームを作成したGoogleアカウントの本人だけ**が見られます
- 他の担当者にも見せたい場合
  - フォーム右上の **⋮** → **共同編集者を追加** でアカウントを追加
  - または、スプレッドシート右上の **共有** から閲覧・編集権限を付与
- 退職・異動を考えると、**個人アカウントではなく採用担当の共有アカウントで作成する**ことをおすすめします

### 保管について

Googleフォーム・スプレッドシートは無料の容量内で利用できます。
応募者の個人情報を扱うため、共有範囲は必要な担当者のみに限定してください。

## 5. 応募フォームの作り方と接続

### ステップ1　フォームを作る

1. [https://forms.google.com](https://forms.google.com) を開く（無料）
2. 「空白のフォーム」を選ぶ
3. タイトルを「学生キャリア開発事業部　応募フォーム」に変更

**設定しておくとよい質問項目**

| 質問 | 形式 | 必須 |
|---|---|---|
| お名前 | 記述式 | ● |
| ふりがな | 記述式 | |
| 大学名・学部・学年 | 記述式 | ● |
| メールアドレス | 記述式 | ● |
| 電話番号 | 記述式 | ● |
| 応募のきっかけ | ラジオボタン（サイトを見て／大学の紹介／友人の紹介／その他） | |
| 聞いてみたいこと・ご質問 | 段落 | |
| 希望する連絡方法 | ラジオボタン（メール／電話） | |

### ステップ2　URLをコピー

右上の **送信** → 鎖のアイコン（🔗）→ 表示された `https://forms.gle/...` をコピー。

### ステップ3　サイトにつなぐ

`assets/config.js` を開き（GitHub上でも編集できます）、次の行にURLを貼り付けて保存。

```js
applyUrl: "https://forms.gle/ここに貼り付け",
```

**これだけで、全ページの「応募する」ボタンが一括でフォームにつながります。**

あわせて次の項目も変更してください。

```js
universityUrl: "",                  // 大学向けに別フォームを使う場合のみ入力（空なら学生用と同じ）
tel: "0120-335-445",                // 電話番号
email: "recruit@ysj-f.co.jp"        // ★仮の値です。実在のアドレスに変更してください
```

## 6. 文章・写真・色の変え方

### 文章

各HTMLファイルの、目印（`▼▼▼ ここから：〜`）を頼りに探して書き換えます。

### 写真

`assets/img/` フォルダに入っています。**同じファイル名で上書き**すれば差し替わります。

| ファイル名 | 使用場所 | 推奨サイズ |
|---|---|---|
| `hero.jpg` | トップの大きな写真 | 横1600px（横長） |
| `office.jpg` | 事業についてページ | 横1000px |
| `meeting.jpg` | トップ（仕事内容） | 横1000px |
| `talk.jpg` | プログラム（金曜MTG） | 横1000px |
| `ceo.jpg` / `event.jpg` / `outing.jpg` | 予備（未使用） | ― |

GitHub上で差し替える場合は、`assets/img` フォルダを開き
**Add file → Upload files** で同名ファイルをアップロードします。

### 色

`assets/style.css` の冒頭を書き換えると、全ページの色が変わります。

```css
--navy:#12304F;      /* 濃い紺（文字） */
--blue:#2C6FB5;      /* アクセントの青 */
--orange:#E8811F;    /* ボタンのオレンジ */
```

## 技術メモ

- HTML / CSS / JavaScript のみ。ビルド作業やサーバー機能は不要です
- スマートフォン・タブレット・パソコンのどの画面幅でも見やすく表示されます
- 外部サービスを読み込んでいないため、閲覧者の情報が第三者に送信されることはありません
